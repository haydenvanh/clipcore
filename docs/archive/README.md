# Archive: the SaaS direction

These documents were written when ClipCore was being built as a public,
multi-user SaaS product with sign-in, subscriptions, and a marketing site.

That direction was dropped on 2026-09-30 in favour of a private, single-user
tool. The code for it was removed; these are kept because the thinking in them
— particularly the competitor analysis and pricing work — may be useful if that
direction is ever revisited.

**Nothing here describes the current application.** For that, see the main
[README](../../README.md).

The removed code is recoverable from git history; the last commit containing
the full SaaS version is the parent of the commit that introduced this file.
